# Agentic Coder (small)

WARNING: This agentic coder built entirely in Python is a case study, not a professional grade system applying all best security practices.

This Python code runs an agentic coder that is given access to a project subfolder "Calculator". Read/write access is granted in a granulor way, with current settings preventing the creation of new exectuables.

The calculator is Python code that can take simple arithmetic equations supplied as a string. This is executed through a CLI.
